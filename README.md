# What are you reading today?

네이밍 그대로, "오늘 뭐 읽어?"라는 질문에서 시작한 뉴몰피즘 독서 아카이브 데스크탑 앱.
Kakao 도서검색 오픈 API와 로컬 저장소를 사용해 내가 읽은 책을 기록/별점/코멘트로 남기고,
마음에 드는 북카드로 내보낼 수 있어요.

<p align="center">
  <em>Electron + Vite + React + TypeScript · Zustand · html-to-image</em>
</p>

## 주요 기능

- **상단 검색** — Kakao 도서검색 API(또는 직접 입력)로 책을 서재에 추가. 추가한 날짜가 기록돼요.
- **좌측 서재** — 읽은 모든 책을 최신순 / 오래된순 / 별점순 / 가나다순으로 정렬.
- **중앙 목록** — "내 목록"(직접 만든 컬렉션) 또는 "카테고리"(API 정보 기반 자동분류)로 전환. 행을 클릭하면 목록 내 도서가 펼쳐지고 다시 클릭하면 최소화.
- **우측 상세** — 표지·저자·출판사·출간일·장르·ISBN·줄거리·내 별점·내 코멘트·목록 소속 관리.
- **북카드 내보내기** — 별점+코멘트가 담긴 뉴몰피즘 카드를 PNG로 저장.
- **커스텀** — 로컬 폰트 선택, 단일 테마컬러 지정(팔레트 자동 생성), 다크 모드.

## 설치

```bash
npm install
```

### 개발 모드

Vite만 돌려보기 (브라우저에서 미리보기, Kakao API는 fetch로 직접 호출):

```bash
npm run dev
```

Electron 앱으로 돌리기:

```bash
npm run electron:dev
```

### 빌드

```bash
npm run electron:build
```

`release/` 하위에 플랫폼별 패키지가 생성돼요.

## Kakao REST API 키

1. [Kakao Developers](https://developers.kakao.com/)에서 애플리케이션을 생성
2. "REST API 키" 복사
3. 앱 실행 후 ⚙ 설정 → "Kakao REST API 키" 붙여넣기 → 저장

키는 기기 로컬에만 저장되며 네트워크 호출은 Electron의 main 프로세스를 통해 이루어져요
(웹 브라우저에서 실행할 때는 렌더러가 직접 fetch).

## 데이터 저장

모든 서재/목록/설정은 `localStorage`(`wryrt.store.v1`)에 JSON으로 저장돼요.
향후 `electron-store` 기반 파일 저장 및 내보내기/가져오기 추가 예정.

## 기술 스택

- **Electron** — 데스크탑 셸 + 메인 프로세스의 Kakao 프록시
- **Vite + React + TypeScript** — 렌더러
- **Zustand (persist)** — 상태 관리/영속화
- **CSS Variables + 동적 팔레트** — 단일 seed 컬러에서 뉴몰피즘 전용 컬러·그림자를 파생
- **html-to-image** — 북카드 PNG 내보내기
